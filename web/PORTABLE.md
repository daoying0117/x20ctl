# X20CTL 网页版 · Windows 便携包

1. 在 Windows 10 或 11（x64）上将 ZIP **全部解压**到普通文件夹。
2. 双击文件夹里的 `start-web.cmd`。启动器会优先在 Microsoft Edge 或 Google Chrome 中打开本机配置页面。请保持启动窗口打开。
3. 配置手柄时打开电脑蓝牙，并在网页中点「连接手柄」。使用数据线、2.4 GHz 接收器或游戏蓝牙模式接入电脑后，可在「输入测试」页查看游戏输入。

包里已包含 Node.js 和 Python。启动窗口会显示实际访问地址。关闭窗口或按 `Ctrl+C` 可以停止服务。
